# spatialcore Documentation

`spatialcore` converts notebook-derived spatial omics workflows into reusable, tested package functions.

Primary workflow areas:

- AnnData and SpatialData I/O
- Xenium, Visium HD, CODEX, and H&E helpers
- Landmark-based Xenium-to-H&E/CODEX alignment and overlay QC
- QC, preprocessing, normalization, clustering, and annotation
- Spatial distances, neighborhoods, niches, and proximity curves
- Differential expression, GSEA, and pathway scoring
- Publication-style plotting and report table generation

The package treats the original notebooks and example files as read-only references.
