# Plotting Policy

Plotting functions follow these defaults:

- 300 DPI save defaults.
- readable journal-style font sizes.
- clean legends and axis labels.
- return figure and axis objects.
- display by default in notebooks.
- do not save unless `save_path` is provided.

Use `show=False` in scripts or tests when a figure should be returned without display.

Shared helpers live in `spatialcore.plotting`.
